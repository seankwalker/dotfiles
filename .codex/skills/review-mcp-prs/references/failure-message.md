# FAIL suggested PR-message draft

Produce one ready-to-post Markdown draft for every FAIL. Start with the exact audited commit SHA:

`Commit audited: \`SHA\``

Follow it with two to five prioritized, concrete, actionable bullets. Cite each finding with a changed-file path and line, a GitHub thread URL, or both. State the required remediation in each bullet.

Add a separate `Missing verification/evidence:` paragraph only when evidence is absent or verification remains incomplete. State what is missing and what would establish it.

Use no generic greeting, sign-off, or boilerplate. Do not claim local checks ran. Do not overstate the evidence or imply a defect beyond what the citations establish.
